이 블로그는 마크다운 파일을 HTML로 변환해서 만듭니다. 프레임워크도 외부 패키지도 쓰지 않았습니다.

## 글 쓰는 방법

`posts/` 폴더에 마크다운 파일을 하나 추가하고 빌드하면 됩니다. 파일 이름이 그대로 주소가 됩니다.

```bash
node build.js
node serve.js
```

쓰다 만 글은 메타데이터에 `draft: true`를 적어 두면 사이트에 나오지 않습니다.

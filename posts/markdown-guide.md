문단은 빈 줄로 구분합니다. 긴 문장을 쓰더라도 한글이 단어 중간에서 끊기지 않아야 읽기 편합니다. 그래서 줄바꿈은 어절 단위로 일어나고, 아주 긴 주소처럼 끊을 곳이 없는 문자열만 예외로 다룹니다.

줄 끝에 공백을 두 칸 넣으면  
이렇게 줄이 바뀝니다.

## 글자 꾸미기

**굵은 글씨**, *기울임*, ***둘 다***를 쓸 수 있습니다. **"따옴표로 끝나는 강조"**에 조사가 붙어도 잘 처리됩니다. `인라인 코드`도 있고, 별표를 그대로 쓰고 싶으면 \*이렇게\* 합니다.

## 코드 블록

코드 블록 안의 문법은 해석하지 않습니다. 긴 줄은 블록 안에서만 가로로 스크롤됩니다.

```js
function greet(name) {
  // **굵게** 처리되지 않고 <태그>도 그대로 보입니다.
  const message = `안녕하세요, ${name}님! 이 줄은 일부러 아주 길게 써서 좁은 화면에서 가로 스크롤을 확인할 수 있게 했습니다.`;
  return message;
}
```

## 표

| 문법 | 예시 | 설명 |
| :--- | :---: | ---: |
| 굵게 | `**글자**` | 강조할 때 |
| 링크 | `[글자](주소)` | 다른 페이지로 연결 |

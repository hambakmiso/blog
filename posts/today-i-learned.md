오늘 클로드 코드로 이 블로그를 만들었습니다. 프레임워크 없이 만들다 보니 웹페이지를 이루는 세 가지 언어가 각각 무슨 일을 하는지 또렷하게 보였습니다. 한마디로 정리하면 이렇습니다.

| 언어 | 역할 | 블로그에서 하는 일 |
| --- | --- | --- |
| HTML | 구조와 내용 | 제목, 본문, 날짜를 담는다 |
| CSS | 모양 | 글자 크기, 여백, 색을 정한다 |
| JavaScript | 동작 | 다크 모드 버튼을 작동시킨다 |

## HTML: 내용과 구조

HTML은 페이지에 **무엇이 있는지** 알려 줍니다. 태그마다 의미가 있어서, 어떤 글자가 제목이고 어떤 글자가 본문인지 구분해 줍니다.

```html
<article>
  <h1>오늘 배운 것</h1>
  <p>오늘 클로드 코드로 이 블로그를 만들었습니다.</p>
</article>
```

## CSS: 모양

CSS는 내용이 **어떻게 보일지** 정합니다. 같은 HTML이어도 CSS에 따라 전혀 다른 모습이 됩니다. 화면 폭에 맞춰 스타일을 바꿀 수도 있어서, 휴대폰에서도 읽기 좋게 만드는 일도 CSS의 몫입니다.

```css
body {
  background: var(--bg);
  color: var(--text);
  line-height: 1.75;
}
```

색을 `--bg`, `--text` 같은 변수로 정해 두면 변수 값만 바꿔서 다크 모드를 만들 수 있다는 점이 특히 재미있었습니다.

## JavaScript: 동작

JavaScript는 사용자의 행동에 **반응하게** 만듭니다. 이 블로그에서는 버튼을 누르면 테마를 바꾸고, 고른 테마를 기억해 둡니다.

```js
button.addEventListener('click', function () {
  var next = root.getAttribute('data-theme') === 'dark' ? 'light' : 'dark';
  apply(next);
  store(next);
});
```

## 배운 점

- 세 언어는 역할이 나뉘어 있어서, 고치고 싶은 내용에 따라 어느 파일을 볼지 알 수 있습니다.
- JavaScript가 없어도 글은 읽을 수 있습니다. 내용은 HTML에 이미 들어 있기 때문입니다.
- 마크다운으로 글을 쓰면 `node build.js`가 HTML로 바꿔 줍니다. 그래서 글을 쓸 때는 내용에만 집중할 수 있습니다.

이 글도 그렇게 마크다운 파일 하나로 올렸습니다.
